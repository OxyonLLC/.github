<h3 align="center">Proof you can check, built on XL1.</h3>

Oxyon LLC builds open tools for **XL1**, XYO Network's blockchain, that make claims **checkable**: an explorer that names the source of every number, a self-custody wallet, evidence records anyone can re-verify, and a kit that turns an old Raspberry Pi into a block producer.

| Product | What it is |
|---|---|
| **[XL1 OxyoNode](https://github.com/OxyonLLC/xl1-oxyonode)** | Turn a Raspberry Pi 3 B+ into an XL1 block producer, with a live dashboard, alerts and a 3.5" touch display. Open source. |
| **[Oxyon Wallet](https://oxyon.io/products/oxyon-wallet)** | Self-custody for XL1, EVM chains and Solana. On [Google Play](https://play.google.com/store/apps/details?id=io.oxyon.wallet), in Chrome and on the [web](https://wallet.oxyon.io/). |
| **[XL1 Explorer](https://oxyon.io/xl1/)** | Watch XL1 live: blocks, transactions, any address, producers and observed health, plus a free [API](https://oxyon.io/docs/developers/api-v1/). |
| **[Evidence Explorer](https://oxyon.io/evidence/)** | Oxyon's evidence records, re-checked in your browser. |
| **[GeoHackers](https://oxyon.io/docs/geohackers/)** | A Discord bot for XL1 communities: wallet verification, a faucet and on-chain proofs. |
